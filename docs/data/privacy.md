# Privacy

| Data | Where | Handling |
|---|---|---|
| Photo GPS (EXIF) | — | Removed before any write (ADR-0007). Event flag `gps_stripped`. |
| Other EXIF (device, timestamps) | bronze only | Dropped in silver (re-encoded JPEG). |
| People in photos | bronze, silver | Not detected or blurred in v0. Do not export photos with people to public datasets. |
| Device ID | operational DB, events | Random UUID generated by the app; not linked to identity. |
| Climber profile (height, ape index, grade) | events, betas | Treated as non-identifying body metrics; never joined with external data. |
| API keys | env only | Never logged; `.env` is gitignored. |

**Retention (v0):** bronze kept indefinitely for training; deletion requests are handled by
device ID across bronze/silver/gold and the operational DB (runbook entry).

**Datasets:** only synthetic and owned/consented images enter gold. Public datasets require their
license recorded in `data/README.md` before use.
